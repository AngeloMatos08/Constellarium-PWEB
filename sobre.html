instrumento de descoberta.

Constellarium é um projeto educativo que aproxima astronomia e desenvolvimento web por meio de uma experiência de reconhecimento de constelações.

01 / PROPÓSITO

Aprender fazendo.
Entender explorando.

A proposta é tornar conceitos de observação celeste mais concretos: em vez de apenas ler sobre constelações, a pessoa joga com a posição das estrelas, experimenta orientar um telescópio virtual e identifica padrões conectando pontos.

02 / ASTRONOMIA

Um sistema para localizar o céu.

Ascensão Reta (RA) e Declinação (DEC) são coordenadas usadas para descrever posições na esfera celeste. No jogo, esses conceitos inspiram os controles de orientação do telescópio.

RA 05h 35mDEC −05° 27′
03 / PROGRAMAÇÃO

Peças pequenas, responsabilidades claras.

O projeto usa JavaScript em módulos ES. Estado do jogo, telescópio, desenho e validação ficam separados para que cada parte possa evoluir sem concentrar tudo em um único arquivo.

04 / COMO FOI CONSTRUÍDO

Uma arquitetura em órbita.

HTML organiza as telas, CSS estabelece a identidade visual e JavaScript conduz as interações. O Canvas desenha o campo de estrelas; os dados locais em JSON alimentam os desafios do protótipo.
